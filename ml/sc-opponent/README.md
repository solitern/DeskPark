# 四川麻将导师：对手模型

导师估算「打出某张牌会不会点炮、点了要赔多少」时，需要猜每个对手听牌了没有、在等哪些牌、胡了有多大。
这里用模拟对局训练一个小型神经网络来做这件事，替换原来的经验公式（`coach/opponents.ts` 里的听牌曲线与危险系数）。

- **数据**：电脑对局里每个人的暗牌都是已知的，正好拿来当标准答案。每当有人轮到自己出牌，就以他为观察者，
  给每个对手记一条样本：输入是观察者能看到的公开信息（`coach/oppfeatures.ts`），
  标签是这个对手现在能胡哪些牌、各几番、是否听牌。
- **模型**：两层 128 维全连接，三个输出头（能胡哪些牌、是否听牌、胡了几番）；约 6 万个参数，
  int8 量化后写进 `coach/oppnet-weights.ts`，在浏览器里用纯 TypeScript 推理（`coach/oppnet.ts`）。
- **对称性**：两门非缺门可以互换、1–9 可以镜像，训练时随机做这两种变换。

## 怎么跑

```bash
# 1. 环境（只需一次；RTX 50 系显卡需要 CUDA 12.8 版 PyTorch）
conda env create -f ml/sc-opponent/environment.yml

# 2. 生成数据（3 万局约 300 万条样本，16 核约 1.5 分钟，约 3 GB，不进仓库）
npx tsx packages/engine/scripts/gen-sc-opp-data.ts --games 30000

# 3. 训练、和经验公式对比，导出权重
conda activate deskpark-ml
python ml/sc-opponent/train.py --export

# 4. 自对弈验证：导师用模型 vs 用经验公式（同一批牌局配对比较）
npx tsx packages/engine/scripts/selfplay-sc.ts --rounds 20000 \
  --params '{"opponentModel":"heuristic"}'
```

改了 `oppfeatures.ts` 的特征时，要把 `OPP_FEATURE_VERSION` 加一，重新生成数据、重新训练；
版本不一致时导师会自动退回经验公式。

## 结果（第 1 版，3 万局 / 300 万条样本，RTX 5060 训练约 40 秒）

| 验证集（另外 3 千局）      | 模型    | 原经验公式 |
| -------------------------- | ------- | ---------- |
| 「这张会不会点炮」AUC      | 0.850   | 0.771      |
| 是否听牌 AUC               | 0.892   | 0.830      |
| 胡牌番数平均误差           | 0.29 番 | 0.41 番    |
| 预测放炮损失与真实值的相关 | 0.256   | 0.133      |

把模型接进导师、并把点炮代价改成「多付的部分」后，自对弈 4 万盘与调好参的经验公式打平
（每盘 +0.012 ± 0.031 分）：电脑对手很少做大牌、也不防守，放炮风险只影响少数决定。
隐藏层加宽到 256 只把 AUC 提高到 0.854，所以保留 128。

## 注意

训练数据来自电脑对局，模型学到的是「电脑对手」的打法——单机练习时正合适；
联机和真人打时，真人的牌型和防守习惯不同，以后可以用真实对局记录再训练。
