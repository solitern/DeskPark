# 路线图

> 每个里程碑对应 GitHub Milestone，具体任务以 Issue 跟踪。欢迎在 Issue 中提出建议。

## v0.1 —— 可玩的基础版 ✅

- 规则引擎插件接口与牌桌运行器
- 斗地主、掼蛋、德州扑克、比大小（示例）
- 单人对电脑、联机房间（建房、加入、补电脑、断线重连、托管、观战、表情）
- 简洁优雅的界面：设计令牌、四种桌布、四色牌、深色模式、合成音效、响应式
- CI、测试（规则单测 + 整局模拟 + 联机集成）、文档

## v0.2 —— 体验打磨

- [ ] 电脑更聪明：斗地主农民配合（当前地主胜率偏高）、掼蛋同花顺与万能牌规划、德州按位置与对手风格调整
- [ ] 难度选择（简单 / 普通 / 困难）
- [ ] 斗地主扩展规则：明牌、加倍、抢地主模式、炸弹上限
- [ ] 掼蛋：过 A 失败三次回 2 的规则选项、出牌记录面板
- [ ] 牌局回放（State 已可序列化，只需记录动作序列）
- [ ] 更多动效：发牌飞入、筹码飞向底池、炸弹特效
- [ ] 新手引导与牌型速查

## v0.3 —— 社交与持久化

- [ ] 房间与对局持久化（Redis），服务器重启不丢局
- [ ] 可选账号（游客 → 绑定），战绩与积分统计
- [ ] 好友房邀请卡片、快捷语音/文字
- [ ] 快速匹配（公共房间）

## v0.4 —— App

- [ ] Capacitor 封装 iOS / Android（见 [PORTING](PORTING.md)）
- [ ] 触感反馈、深链接进房、横屏锁定
- [ ] 应用图标与启动页

## v1.0 —— 自定义玩法

- [x] 升级（拖拉机）：已作为「双升」内置，支持语音报牌与大模型接管
- [x] 河洛杠次（洛阳杠次）：已内置，支持大模型接管
- [ ] 更多内置玩法：跑得快、二十一点、争上游
- [ ] 「规则配置 + 通用牌桌」：无需写代码即可组合简单玩法（牌堆、手牌数、出牌/比较规则、计分）
- [ ] 玩法包：社区贡献的玩法以独立包的形式加载
