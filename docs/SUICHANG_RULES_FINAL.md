# 遂昌麻将 · 定稿（v1）

规则按你填的内容与最后确认的 6 个答案整理；代码已按这一版实现（`suichang-1`）。

## 一、牌与开局

- 4 人，136 张（万、条、筒、东南西北、中发白），无花牌，无定缺。
- 庄家 14 张先出，其余 13 张。
- **翻财神**：从牌墙尾翻一张，**翻到的这张牌的种类**就是财神；翻开的牌移出牌墙，所以该种类只剩 **3 张**，这 3 张是**万能财神**。
- **白板替身**：4 张白板全部变成翻出的那张牌的普通牌（翻到一万 → 4 张白板都当一万，可以吃、碰、杠、点炮；不是万能牌）。翻到白板时，3 张白板就是万能财神。
- 摸牌从牌墙头，杠后补牌从牌墙尾。
- 牌墙留最后 **34 张**不摸（摸完 102 张）即荒庄。

## 二、财神

- 财神只有**翻出的那一种牌**（3 张）；白板是该种类的普通牌，不是财神。
- 财神可以当任意牌用：补面子、补将、单吊都行；**可以做将**。
- 不能碰、杠、吃，不能参与任何副露。
- 可以主动打出，叫**飞财**；打出的财神作废，谁也不能碰杠吃胡。
- **飞财**：飞财之后，**下家、对家、上家各摸一次**的这一圈内：
  - 所有人不能吃、碰、明杠、抢杠，也不能点炮胡——**只能靠摸牌进张、只能自摸胡**；
  - **暗杠、补杠可以**；
  - **只有飞财者本人**，在这一圈结束后的下一次自摸 **+1 番**；
  - 一圈走完（轮到飞财者摸牌）后恢复正常。
- 一局里可以飞多次，不限。

## 三、行牌

- 只能吃上家；碰、明杠、暗杠、补杠都可以；杠后从牌墙尾补牌。
- 补杠可以被抢杠；飞财这一圈内不能抢杠。
- **截胡**：多人同时能胡时，只算按出牌顺序**最近的一家**；另外两家仍然各付 1 份。
- 优先级：胡 > 杠 > 碰 > 吃。
- 碰 / 杠 / 吃之后必须打一张。
- 无过水、无包三家。

## 四、胡牌与荒庄

- 4 面子 + 1 将；七对；豪华七对；清一色、混一色、碰碰胡、字一色、**不搭**（含七风）；**全落地**（吃碰杠后手牌只剩一张）；**七对敲头 / 豪华七对敲头**（6 对 + 财神）。
- 自摸 + 点炮都能胡；**敲头（含七对敲头）只能自摸**，不能被点炮/截胡。
- 一家胡牌，本局立即结束。
- 无海底、无门清、无杠上炮（杠后打出的牌被胡按普通点炮算）。
- **荒庄**：庄家给其余三家每人 **5 分**（固定 5，不按庄底分）；庄家继续坐庄，底分 +2。
- 连庄底分：6、8、10……无上限，下庄后重置为 6。

## 五、不搭（形式化，默认）

- 14 张、**无副露**；所有牌的种类互不相同；同一门里任意两张点数差 ≥ 3；字牌互不相同。
- **普通不搭** = 平胡（0 番）。
- **特殊不搭**：正好 5 张字牌 + 三门各 3 张，且每门的 3 张正好是 `147 / 258 / 369` 之一：
  - 三门同一种 → **超豪华 +3**
  - 2+1 → **正规 +1**
  - 三种都有 → **豪华 +2**
- 不搭可以点炮胡；财神可以替代任意一张来凑不搭。
- **不搭判定时，白板替身一律算白板字牌**，不算它替代的那张牌（例如替四万的白板，在不搭里算白板，不算四万）；真财神仍然是万能牌。
- **七风**：不搭手里**东南西北中发白七张字牌齐全**，+1 番。不能用财神补缺；除非这个财神本身就是缺的那一种（例如翻到东风，东风财神可以当东风用）。
- **全落地**：吃、碰、杠之后手牌只剩一张（4 组副露 + 将），+1 番。

## 六、番数与计分

- **平胡 = 0 番 = 1 倍**；**倍数 = 2^番**；不封顶。
- 牌型番：
  - 碰碰胡 +1
  - 混一色 +1
  - 七对 +1
  - **豪华七对 = 2 番**（七对 1 + 豪华 1，不和七对重复算）
  - 清一色 +2
  - 清碰 = 清 2 + 碰 1 = 3
  - 清七对 = 清 2 + 七对 1 = 3
  - 清豪华七对 = 清 2 + 豪七 2 = 4
  - 字一色 +3；如果同时是碰碰胡再 +1
  - 不搭：正规 +1 / 豪华 +2 / 超豪华 +3
  - 七风 +1（七张字牌齐全）
  - 全落地 +1（4 组副露 + 将）
  - **敲头 +1**：4 面子 + 财神，或 6 个对子 + 财神；听所有牌，只在自摸时发生，不能点炮。平胡敲头连同自摸 = 2 番；**七对敲头 = 七对 1 + 敲头 1 + 自摸 1 = 3 番（8 倍）**；豪华七对敲头再加豪华 1 = 4 番（16 倍）。
- 过程番：自摸 +1、杠上开花 +1、天胡 +2、地胡 +2（天胡 / 地胡本身就是自摸，**不再叠自摸**）、飞财自摸 +1（只有飞财者）。
- **底分基数 B**：一笔钱只要涉及庄家（庄收或庄付）就用**庄家底分**（6/8/10…），两个闲家之间用 **5**。
- **自摸**：其余三家各付 `B × 2^番`。
- **点炮**：点炮者付 `2 × B × 2^番`，其余两家各付 `B × 2^番`。
- **抢杠**：A 补杠、B 抢杠胡时，只有 A 付 B，金额 = `50 × 2^牌型番`（平胡 50、碰碰胡 100），抢杠本身不加番，**一盘结束再结算**。
- **荒庄**：庄家给三家各 5。
- **筹码**：每人每盘 50，底分 5；有人筹码为 0 时本盘结束（只付到 0），结算后重置 50 继续；同一手把三家都打到 0 为**三清**，三家各额外付 50（赢家净 +300），与抢杠一起在盘末结算。

## 八、已确认的细节

1. **清碰自摸**：闲家每家 **80**（清 2 + 碰 1 + 自摸 1 = 4 番 16 倍）。
2. **天胡 / 地胡**：都算自摸，但**不再叠自摸番**；天胡（庄家）每家 **24**（天胡 2 番 = 4 倍 × 6）。
3. **抢杠承包**：A 补杠、B 抢杠胡时，**只有 A 付 B**（其余两家不付）；金额 = **50 × 2^牌型番**（平胡 50、碰碰胡 100），抢杠本身不加番；**一盘结束再结算**。
4. **筹码清零**：只付到 0（只剩 5 就付 5）；**同一手把三家都打到 0** 才是三清，三家各额外付 50；三清的额外 50 与抢杠一起在一盘结束时结算（允许最终为负）。
5. **牌墙**：留最后 **34 张**不摸（即摸完 102 张）荒庄；杠后从牌尾补牌、翻财神从牌尾翻。
6. **飞财 +1**：飞财者这一圈走完、**下一次摸牌自摸**时 +1，没自摸则作废；圈内所有人（包括飞财者）不能吃碰、明杠、抢杠、点炮胡，只能自摸；暗杠、补杠可以。
