注：

1. 胡牌计分示例：一庄自摸，收+12+12+12；二庄点炮胡，收+16+8+8；非庄家点炮胡，收+10+6（庄）+5；清一色碰碰胡，清一色+2番，碰碰胡+1番，总共3番（8倍），如果自摸则收40+40+48；财神头我们叫爆头，也就是4面+1财神，此时听所有牌，轮到自己时自摸即是爆头，听爆头时无法截胡，爆头为2番。
2. 我们还有不搭的牌型，也就是字牌（至少五张）+散牌型。一般的不搭等于平胡；特殊不搭牌型：147、258、369的牌型，看组合情况，每种都有（如147条+258筒+369万）为豪华，番数+2；只有一种（如147条+147筒+147万）为超豪华，番数+3；2+1（如147条+147筒+258万）为正规，番数+1。
3. 可以飞财神，飞财后一圈自摸加一番。（飞财这一圈中其余人无法吃碰和点炮胡，只能自摸胡）



## 6. 流程与结束

| 项目     | 可选                                                  | 我们的规则                          |
| -------- | ----------------------------------------------------- | ----------------------------------- |
| 起手张数 | 庄家 14 张、其余 13 张（推荐默认）                    |                                     |
| 盘数     | 4 / 8 / 16 / 不限                                     |                                     |
| 结束条件 | 打完设定盘数（推荐默认）/ 有人筹码输光 / 其他：______ |                                     |
| 筹码     | 不用（推荐默认）/ 每人初始 ______ 分，有人输光结束    |                                     |
| 荒庄之后 | 连庄（推荐默认）/ 下庄 / 其他：______                 | 连庄，并且给其余三人每人5分（底分） |
| 结算展示 | 台型明细 + 本盘得分 + 总分（推荐默认）/ 只要总分      |                                     |

我们是这样的，每一轮每人50个筹码，底分是5个筹码。当一个人50输完时，这一盘结束，可以继续下一盘或结束。当一个人把其余三人的筹码都清空时，为三清，此时每人需额外支付50筹码。
